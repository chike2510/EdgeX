# Approved EdgeX mockup implementation specification

## Visual system

The production UI uses one deep mineral-green surface: `#07120F` for the page background, `#101C1A` for panels, `#1D3730` for borders, `#A9D9C3` for secondary text, `#EDF8F1` for primary text, and `#63E6A7` for the single positive accent. Instrument Serif is reserved for editorial display headlines. Plus Jakarta Sans is used for navigation, labels, metadata, body copy, controls, and data states.

## Shared shell

Every route uses the same compact top bar: a thin three-stroke menu control, small EDGE X wordmark, an INTELLIGENCE eyebrow, the current page title, and two restrained action controls. Mobile uses a slim five-item bottom bar. Desktop uses the same hierarchy with a persistent drawer/rail. There is no second brand header on Home or Landing.

## Mobile drawer

The drawer is narrow and calm, with a 40px close control, 44px navigation rows, small line icons, separated Workspace / Intelligence / Account labels, and a restrained Live provider context footer. It must not inherit legacy page navigation positioning.

## Landing and Home

Landing is a clean intelligence introduction below the shared shell, not a separate marketing product. Home is a compact overview below that same shell. Both use the same typography, card radius, border weight, spacing scale, and bottom navigation as intelligence pages.

## Football context

Football’s mobile context bar contains only Back, FOOTBALL · APEX, and Live. Insights and History remain available without being forced into the narrow context row. Date, live/fixtures/results, competition filters, search, and sort controls remain separate rows.

## Integrity

Do not fabricate market probabilities, confidence, reviews, provider statuses, or match content. Empty and unavailable states must be explicit and calm.
